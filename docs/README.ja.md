# Dofodo

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22512610.svg)](https://doi.org/10.5281/zenodo.22512610)

このゲームは BoardGameGeek に登録されています：[Dofodo (2026)](https://boardgamegeek.com/boardgame/476432)。

ブラウザで遊ぶ：<https://telesik.github.io/dofodo/> — 1つの画面で2人、またはボットと対戦。

**普通のドミノセット**（28枚、ダブルシックス）で遊ぶボードゲームですが、ルールはまったく
別物です。従来のドミノではありません。同じ目をつないで一本の鎖にすること、伝統的なブロック
ゲーム、残り牌での得点計算は、ここではどれも違う働きをします。

## どんなゲームか

ラウンドはダブル、つまり**根**から始まります。そこから木が育ちます。普通の牌を90°に置くと
**分岐**ができて開いた端が一つ増え、ダブルを横向きに置くと枝は永久に**閉じ**ます。

ここに中心的な対立があります。ラウンドは誰も牌を置けなくなったときに終わり、得点は手に多く
残した方に入ります。だから軽い手札のプレイヤーは閉じることでラウンドを締め上げ、重い手札の
プレイヤーは分岐して時間を稼ぎ、牌を減らそうとします。ラウンドの長さそのものが争いの的です。

もう一つの特徴：**手札は公開して遊びます**。牌は表向きで、チェスのように両者に見えています。
唯一の運の源は裏向きの山札です。

## 作者

**Alexey Kiselyov** と **Olga Popova**。

私はこのゲームを、愛する妻オレチカのために2026年7月31日の夜に作りました。普通のドミノで
気になっていたのは運に左右される度合いの大きさでしたが、運を完全になくしたくもありませんでした。
そこで手札を公開し、裏向きの山札だけを運の源として残しました。

思いつきを手早く書き留め、私たちはすぐに遊び始めました。その夜のうちにオレチカがダブルを
まっすぐ置くことも認めようと提案し、プレイヤーに選択が生まれて、その規則が主なものになりました。
最初の版ではダブルは常に枝を閉じていました。

いきさつの全文は [RULES.ja.md §14](RULES.ja.md) にあります。

## 状況

2人用ルールは完成しています。第1.1版は2026年9月に恒久的な識別子（冒頭のDOI）付きで公開されました。
ルールそのものは初版から変わっておらず、向きを変えた牌の置き方が明確になっただけです。3人以上の
モードは意図的に先送りしています（[RULES.ja.md §12](RULES.ja.md)）。

遊び方：

- **ブラウザで** — <https://telesik.github.io/dofodo/>：1つの画面で2人、またはボットと対戦。
- **iPhone と iPad で** — アプリ [Dofodo（App Store）](https://apps.apple.com/app/id6801880127)：1つの画面で2人、3段階の強さのボットと
  対戦、または並べた2台の電話で Bluetooth 対戦。インターネット不要。無料、広告なし、アカウント
  不要、データ収集なし。インターフェースは11言語。
- **Android で** — Google Play 版はクローズドテスト中で、承認後に公開します。

ゲームは2026年7月31日の夜に考案され、以来何度も遊ばれてきました。2人で、ボットと、そしてアプリの
テスターによって。バランスについて結論を出すにはまだ足りません。観察は「バランスに関する覚え書き」
（[RULES.ja.md §13](RULES.ja.md)）にまとめています。

名前は2026年9月に、BoardGameGeek、アプリストア、商標登録簿（TMview、EUIPO、WIPO）を
確認したうえで選びました。
