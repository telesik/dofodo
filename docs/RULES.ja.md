## 1. 用語

| 用語 | 意味 |
|---|---|
| **先手** | 現在のラウンドで最初に手番を行う人。役割はラウンドごとに決め直します（§2.5）。 |
| **後手** | 現在のラウンドにおける先手の相手。 |
| **ダブル** | 両側の目が同じ牌（0-0、1-1、…、6-6）。セットに7枚あります。 |
| **根** | ラウンドの起点となるダブル。テーブルに置かれる最初の牌。 |
| **山札** | 配られなかった牌を裏向きにして積んだもの。 |
| **端** | 配置の縁にある開いた目で、そこに牌をつなげられます。 |
| **枝** | 分岐（または根）からいずれかの端まで続く牌の連なり。 |
| **分岐** | 枝が二方向に分かれる地点（§6.3）。 |
| **直進端** | 分岐の端のうち、牌をつないだ目をそのまま保つ方。 |
| **分岐端** | 分岐の端のうち、つないだ牌の空いた半分が作る方。 |
| **新しい端** | まだ牌がつながれていない分岐の端（§6.4）。 |
| **閉じた端** | 横向きに置かれたダブルで封じられた端（§7.1）。もう伸ばせません。 |
| **行き止まり** | もう牌をつなげない端。その目を持つ7枚の牌がすべてテーブルに出ています。 |
| **まっすぐ** | 牌の置き方の一つ。枝を分けずに延長します。 |
| **曲げる** | 牌の置き方の一つ。枝を分けます。 |
| **やむを得ない曲げ** | 牌を端に横からつなぎ、最初から脇にずらして置くこと。ルール上は「まっすぐ」です。分岐は生まれず、テーブル上で枝の向きが変わるだけです（§6.3）。（枝を伸ばす場所がない狭いテーブルのための純粋に実用的な工夫で、ルールには影響しません。） |
| **横向き** | ダブルの置き方の一つ。端を閉じます。 |
| **ブロック** | どちらのプレイヤーも牌を置けない状態（§9.1）。ロシア語原典では *ryba*「魚」と呼びます。 |
| **上がり** | プレイヤーが手札の最後の牌を置いたこと（§9.2）。 |
| **ラウンド** | 1回の配牌から、ブロックまたは誰かの上がりまで。 |
| **マッチ** | 100点まで行うラウンドの連続（§10.5）。 |

## 2. 用具と準備

2.1. ごく普通のドミノセット：28枚、ダブルシックス。他には何も要りません。

2.2. 2人で遊びます。現在のラウンドで最初に手番を行う人が**先手**、その相手が**後手**です。
これは1ラウンド内の役割であって固定の立場ではありません。先に手番を行う権利はラウンドごとに
移る（§2.5）ので、普通は次のラウンドで役割が入れ替わります。

2.3. 各ラウンドの前に28枚すべてを混ぜ直します。各プレイヤーは**7枚**を引き、**14枚**が
山札に残ります。

2.4. 先手は7枚をすぐに**表向き**で引きます。後手は**裏向き**で引き、最初に手番が移るまで
手札を伏せておきます（§3）。

2.5. **先に手番を行う権利。**
- マッチの最初のラウンドではランダムに決めます。コイントス、引いた牌の小さい方、何でも構いません。
- それ以降のラウンドでは、**前のラウンドの勝者**が先手です（§10.4）。
- 前のラウンドが**引き分け**なら勝者はおらず、単に**交代**します。前のラウンドで後手だった人が先手になります。

> 先手の立場はわずかに不利だと想定しています。相手の手札を何も知らないまま、手番の前に自分の
> 手札を公開するからです。そのため最初の手番は勝者に与えられます。統計が逆を示すなら、つまり
> 先手の方が勝ちやすいなら、ルールは「前のラウンドの敗者が先手」に変わります。

## 3. 公開手札 — このゲームの特徴

3.1. ゲームは**手札を公開して**行います。両プレイヤーの牌は表向きで、誰からも見えます。

3.2. **唯一の例外は最初の手番です。** 先手は牌を引いた時点（§2.4）、つまり最初の手番の
**前**から公開です。後手は先手の手番が終わるまで牌を伏せておきます。

3.3. 先手の手番が終わり次第、**どんな終わり方であっても**（根を置いた、牌を引いた、パスした）、
後手は手札を公開します。

3.4. それ以降ラウンドの終わりまで、両方の手札は公開です。§3.2 の非対称は**ラウンドに1回**
だけ適用され、先に手番を行う権利の埋め合わせになります。

3.5. **山札は常に裏向きです。** これは意図的なものです。手札はチェスのように公開され、山札が
ゲームに残る唯一の運の源です。中身は推定できますが（28からすべての見えている牌を引く）、
牌の順番は分かりません。

## 4. 基本ルール：置けるなら必ず置く

4.1. 手番のプレイヤーは**置けるなら必ず置かなければなりません**。これはラウンド全体、
根を探している間もその後も適用されます。

4.2. 合法手があるのにパスすることはできません。合法手があるのに山札から引くこともできません。

4.3. 帰結：
- 根がまだ置かれていない状態でダブルを持っている → 根を置かなければならない（§5.2）；
- 根を探している間にダブルを引いた → それを置かなければならない（§5.3）；
- 置ける牌を引いた → それを置かなければならない（§8.2）；
- 唯一の合法手が悪手 → それでも打たなければならない。§11.1 の罠はまさにこれに基づきます。

## 5. ラウンドの開始：根を探す

5.1. ラウンドは必ずダブルから始まります。**どの**ダブルでも構いません。それが根になります。

5.2. 手番のプレイヤーは、ダブルを持っていれば必ずそれを根として置きます（§4.1）。複数
持っていれば、どれを根にするかを選びます。

5.3. ダブルを持っていなければ、山札から1枚引きます（§8）。
- ダブルを引いた → それを根として置かなければならない。
- それ以外を引いた → 手元に残し、手番を渡す。

5.4. §5.2–5.3 の手順は、誰かが根を置くまで繰り返します。

5.5. これが行き詰まることはありません。セットにはダブルが7枚あるので、山札が空になれば
すべてのダブルは必ずプレイヤーの手札にあります。

## 6. 根を置いた後の進行

6.1. プレイヤーは、開いた端のいずれかと目が一致する牌を置かなければなりません（§4.1）。

6.2. **根は一方向にしか伸びません。** 根の左側は使わず、根の上下にも枝は伸びません。
実質的に根が提供する開いた端は**1つ**です。

```
使わない ←── [4|4] ──→ 開いた端「4」
```

6.3. 普通の牌（ダブル以外）は**まっすぐ**か**曲げて**置きます。

**まっすぐ** — 牌は枝を同じ方向に延長します。つないだ半分が古い端を封じ、空いた半分が新しい端に
なります。開いた端の数は変わりません：

```
前：  … ── [3|5] ──→ 端「5」
後：  … ── [3|5] ── [5|4] ──→ 端「4」
```

**曲げる** — 牌は枝の空いた端につなぎますが、90°回転させます。これで**分岐**ができ、
**異なる**目を持つ自由な方向が二つ生まれます：

- **直進端** — 牌をつないだ目（例では「5」）。生きたままで、枝は方向を保ちます；
- **分岐端** — つないだ牌の空いた半分（例では「4」）。この枝は直進方向に対して90°に走ります。

```
前：  … ── [3|5] ──→ 端「5」

後：  … ── [3|5] ──→ 直進端「5」
                   │
                  [5]
                  [4]
                   ↓
               分岐端「4」
```

*分岐は古い端を消費せず、新しい端を**追加**します。開いた端の数は1増えます。*

**テーブルへの置き方：分岐とやむを得ない曲げ。** 物理的には、90°回転させた牌は端に二通りの
方法で接することができ、第1.1版からこの二つは異なる意味を持ちます。

- **方法1 — 列と面一に：本物の分岐。** つないだ半分は直進する枝に沿って置かれ、空いた半分が
  脇に突き出します。これが「曲げる」手です。端は直進端と分岐端の二つになり、どちらも生きて
  います。アプリも牌をこのように置きます。
- **方法2 — 最初から脇にずらして：やむを得ない曲げ。** 牌は端に横からつながれ、つないだ半分は
  列を続けずにその隣に置かれます。ルール上これは**「まっすぐ」**の手です。古い端は封じられ、
  新しい端は牌の空いた半分となり、開いた端の数は変わりません。テーブル上で枝の向きが変わる
  だけです。まっすぐの手のルールがすべて適用されます。やむを得ない曲げは新しい端でも許され
  （§6.4）、この端に次に置く牌は再び自由です。まっすぐ、曲げる、ダブルを横向き、いずれも可能です。

なぜこれが必要か。第一に場所です。小さなテーブルでは枝を延ばす場所がなくなることが多く、
やむを得ない曲げがなければ枝全体を置き直す必要があります。第二に読みやすさです。脇にずらした
牌は目には分岐ではなく列の向きの変化として映ります。この約束事は、目に見えているものを
そのまま定めるだけです。

![列と面一に置かれた曲げ牌 6:1](img/turn-inline.jpg)

*方法1：牌 6:1 は列と面一に置かれています。「6」の半分が直進する枝に沿っています。分岐です：右に直進端「6」、下に分岐端「1」。*

![同じ牌 6:1 を最初から脇にずらして置いたもの](img/turn-sideways.jpg)

*方法2：同じ牌 6:1 を最初から脇にずらして置いたもの、やむを得ない曲げです。ルール上は 6:1 をまっすぐ置くのと同じです。端「6」は封じられ、枝は端「1」で下へ続きます。*

どちらの写真にも上部に**閉じた端**が写っています。縦の枝が、横向きに置かれたダブル 1:1 に
突き当たっています（§7.1）。

6.4. **新しい端の制限。** 分岐のどちらの端であれ、直進端でも分岐端でも、最初につなぐ牌は
**まっすぐ**に置かなければなりません。新たな分岐を作ることも、横向きのダブルで端を閉じる
こともできません。

言い換えれば、**分岐の直後の分岐は禁止**であり、**生まれたばかりの端を閉じることもできません**。

この制限は端ごとに別々に適用され、その端に1枚でも牌がつながれた時点で解除されます。それ以降は、
その端で再び分岐も閉じることも可能です。

*例。* 端「5」（直進）と「4」（分岐）を持つ分岐。4:1 を曲げて置くことはできず、5:6 を曲げて
置くこともできず、「5」も「4」もダブルで閉じられません。たとえば 5:6 をまっすぐ置くことは
できます。その後、「5」から伸びた端は再びどんな手にも開かれますが、端「4」はまだ新しいままです。

6.5. 分岐は §6.4 の場合を除き、**どの**手番でも可能です。

6.6. **唯一の例外は根の直後の最初の牌です。** 根の端もやはり「新しい」のですが、この牌は
曲げて置いても構いません。これは権利であって義務ではありません。

## 7. ダブルと枝を閉じること

7.1. ダブルは特別な牌です。置き方は**二通りだけ**です：

- **まっすぐ** — ダブルは普通の牌のように枝に**沿って**置かれます。端は開いたままで、
  **同じ**目を保ちます：

```
… ── [3|5] ── [5|5] ──→ 端「5」
```

- **横向き** — ダブルは**枝の方向を横切るように**置かれます。枝は**閉じられ**、
  もう伸ばせません：

```
                ┌───┐
                │ 5 │
… ── [3|5] ─────┤   │   ✕ 枝は閉じた
                │ 5 │
                └───┘
```

閉じた枝の実例は §6.3 の写真を参照してください。上部の縦の枝が、横向きに置かれたダブル 1:1 に
突き当たっています。

7.2. **ダブルを曲げて置くことはできません。** ダブルで分岐は作れません。

7.3. 端を閉じられるのは**対応する**ダブル、つまり端の目と同じ目のダブルだけです。

7.4. 新しい端は閉じられません（§6.4）。そのような端に最初の牌として置くダブルは、**まっすぐ**
にしか置けません。

## 8. 山札から引く

8.1. 手番のプレイヤーが山札から引くのは**最大1枚**です。根を探している間も、本番の段階でも同じです。

8.2. 引くのは合法手がないときだけです（§4.1）。その後：
- 引いた牌で手が打てる → 必ずそれを置き、手番は終わる；
- 引いた牌が役に立たない → 手元に残し、何も置かずに手番を渡す。

8.3. 山札が空で合法手もなければ、プレイヤーは何もせずにパスします。

## 9. ラウンドの終了

ラウンドは次の二つのいずれかで終わります。

9.1. **ブロック** — 誰も牌を置けない状態です。開いた端がすべて、閉じている（§7.1）か
行き止まり（その目の7枚がすべてテーブルに出ているため、合う牌がどちらの手札にも山札にも
残っていない）かのどちらかです。すべての端が閉じているのはその特殊な場合です。

9.2. **上がり** — プレイヤーが手札の最後の牌を置き、手元に何も残っていない状態です。

9.3. ブロックのときは山札から引きません。すぐに得点を数えます（§10）。

## 10. 得点とマッチの勝敗

10.1. ラウンドが終わると、各プレイヤーは**手に残った牌の目の合計**を数えます。各牌の両半分の
数字をすべて足したものです。上がったプレイヤー（§9.2）の合計は0です。

10.2. **ダブル 0:0 は特別な値です。** 0:0 がプレイヤーの**唯一**残った牌なら、**25点**と数えます。
他に1枚でも牌があれば、0:0 はいつも通り**0**です。

10.3. **合計が厳密に少ないプレイヤーだけが得点しません。** それ以外の全員が自分の合計を自分の
累計に加えます。2人の場合はこうなります：

- 合計が異なる → 多い方が自分の合計を自分の累計に加え、少ない方は何も受け取らない；
- 合計が**同じ** → **両者**が加える。

10.4. **ラウンドの勝者**は合計が厳密に少ないプレイヤー、つまり得点しなかった方です。合計が
同じならラウンドに勝者はいません。勝者は次のラウンドで先手になります（§2.5）。

10.5. **マッチの終了。** 集計の後で少なくとも一方が**100点以上**になった時点でマッチは終わります。
**累計が多い方が負けです。** 累計が同じなら（たとえば103対103）、マッチは**引き分け**で
勝者はいません。

## 11. ルールのバリアント

11.1. **「ダブルは閉じるだけ。」** ダブルをまっすぐ置くことはできず、枝を閉じる（横向き）
ことしかできません。したがって自動的に、ダブルは新しい端の最初の牌にはなれません。そこで
閉じることは許されず（§6.4）、このバリアントではダブルに他の選択肢がないからです。

**これがルールの元々の版です**。ゲームは最初このように考案されました。ダブルをまっすぐ置く
ことは同じ夜、最初の数ラウンドの間に導入されました（§14）。

このバリアントは**罠**を生みます。ダブルは安全な牌ではなくなり、相手に最悪のタイミングで
ラウンドを終わらせることを強いることができます。例：根が 2:2 で、後手が 2:1 をまっすぐ置きます。
先手の手札が 1:1 だけなら、置かなければならず（§4.1）、置く方法は横向きしかありません。
それが唯一の端を閉じてラウンドを打ち切り、手にどれだけ点が残っていても関係ありません。

現在は §7.1 のバリアントが主なものとされています。ダブルは延ばすことも閉じることもできます。
より穏やかで選択も多いのですが、罠はなくなります。両方試す価値があります。

## 12. 先送り

12.1. **3人以上用のモード。** 2人用ゲームの実装後に再検討します。（28枚：3人に7枚ずつ →
山札は7枚；4人に7枚ずつ → 山札なし。）

## 13. バランスに関する覚え書き

*ルールではなく、仕組みから導かれる帰結です。再び考え直さなくて済むよう記録しておきます。*

13.1. **端の収支。** まっすぐ → 端の数は変わらず；曲げる → +1；横向きのダブルで閉じる → −1。
ラウンドは端1つから始まります（§6.2）。

13.2. **ゲームはごく速くブロックされうる。** 最短のラウンド：根 → 牌をまっすぐ1枚 →
横向きのダブル。テーブルに3枚、両者はほぼ丸ごとの手札を持ったまま。これこそが合計の少ない
側の速攻勝ちです。

13.3. **速攻の閉じに対する防御は分岐。** 分岐はいつでも可能です。合う牌でダブル以外なら何でも
曲げて置け、§6.4 は相手が新しい端をすぐ閉じるのを妨げます。重い手札のプレイヤーは分岐で
ラウンドを引き延ばし、軽い手札のプレイヤーは閉じることでラウンドを締め上げます。ラウンドの
長さを直接争うのであり、これがゲームの中心的な対立です。最初の数ラウンドの実戦では仕組みは
均衡しているように感じられます。より広いテストで確かめます。

13.4. **分岐の上限。** 端の数を0にするには、分岐の数より1回多く閉じる必要があります。ダブルは
7枚で1枚は根に使われる → 閉じは最大6回 → 1ラウンドの分岐は最大5回。**分岐が6回以上作られる
と、すべての端を閉じてゲームをブロックすることは不可能**になり、ラウンドは誰かの上がりか
端の行き止まりでしか終わりません。まっすぐ置かれたダブルは、そのたびに上限をさらに1下げます。

13.5. **まっすぐ置かれたダブルは鍵を永久に燃やす。** 同じ牌は2枚とないので、その後その目を
持つ端は二度と閉じられず、干上がらせるしかありません。

13.6. **ゼロへの二つの道。** 上がり（§9.2）は合計0を保証し、それは必ず厳密に少ないので、
1点も失いません。これによりプレイヤーには二つの異なる作戦があります。軽い手札を持ったまま
ゲームをブロックするか、手札を空にするかです。分岐は後者に、閉じは前者に役立ちます。

13.7. **なぜ 0:0 が25点なのか（§10.2）。** このルールがなければ 0:0 は抱え込むのに最適な牌に
なります。最後まで無料で持ち続けられ、0:0 しか持たないプレイヤーの合計は0なので、上がった
相手に対してさえ支払いません（0対0は同点で、どちらも支払わない）。ルールはこれを逆転させ、
最後に残った 0:0 はセットで最も高価な牌になります。

13.8. **同点は両者を罰する。** 合計が同じなら両者が支払う（§10.3）ので、安全なのは厳密に少ない
合計だけです。敗者が差ではなく合計**全額**を加えることと合わせて、終盤は鋭くなります。
41対40では、1点の差が41点の代償になります。

13.9. **短いマッチでも構わない。** セットの牌の平均は6点なので、7枚の手札は約42点です。速攻の
ブロック（§13.2）はそのほとんどを手に残すため、そういうラウンドが1回あれば敗者に一度に40〜50点が
入り、100点マッチは2〜3ラウンドで終わります。これはこのまま受け入れます。マッチの長さは定数
ではなく戦いの結果です。不利なプレイヤーには、分岐してラウンドを引き延ばし、より多くの牌を
捨てる理由が十分にあり、それがどれだけうまくいくかが、マッチが短いか長いかをまさに決めます。

13.10. **先に手番を行う権利：増幅か追い上げか。** 最初の手番は勝者に行きます（§2.5）。先手の
立場が本当に弱いなら、これは追い上げの仕組みとして働き、マッチを接戦に保ちます。逆に先手が
有利だと判明すれば、ルールは逆に作用してリーダーとの差を広げます。統計が示すべきはそこです。

13.11. **公開手札と着手義務は完全情報を意味する。** プレイヤーの決定は、合う牌のどれを置くか、
どの向きに置くかに帰着します。残る唯一の運は裏向きの山札にあります（§3.5）。

## 14. このゲームが生まれた経緯

私はこのゲームを、愛する妻オレチカのために2026年7月31日の夜に作りました。

普通のドミノで気になっていたのは、運に左右される度合いの大きさでした。結果を決めるのが
プレイヤーの選択ではなく、たまたま出た牌であることがあまりに多かったのです。それでも運を
完全に取り除きたくはありませんでした。運がなければスリルが消えてしまいます。そこからこの
ルールの特徴が生まれました。手札はチェスの駒のように公開され、残る唯一の運の源は裏向きの
山札です（§3.5）。

私は思いつきを手早く書き留め、私たちはすぐに遊び始めました。一晩中遊びました。最初の版は
もっと厳しく、ダブルは横向きにしか置けず、常に枝を閉じていました（§11.1）。オレチカが
まっすぐ置くことも認めようと提案し、プレイヤーに選択が生まれ、その規則が主なものになりました
（§7.1）。

このゲームが気に入ったので、私はルールを書き留めたのです。
